# Nudee & Nadia — Student Portfolio Website
**Anglo Singapore International School (Secondary 3 & Secondary 1)**

🌐 **Live Website (GitHub Pages):** [https://rchookhiatti.github.io/nudee-nadia-portfolio/](https://rchookhiatti.github.io/nudee-nadia-portfolio/)

---

## Overview
An interactive academic and co-curricular portfolio showcasing sisters **Nudee (Secondary 3)** and **Nadia (Secondary 1)** at **Anglo Singapore International School**.

### Key Features
1. **Sister Switcher (`Both Sisters` | `Nudee (Sec 3)` | `Nadia (Sec 1)`)**: Dynamically filter the entire portfolio to view both sisters side-by-side or focus on either sister's individual profile, color theme, and achievements.
2. **Academic Excellence & Trilingual Mastery**: Displays subject grades, Singapore-Cambridge curriculum progress, and trilingual proficiency (English, Mandarin Chinese HSK, and Thai).
3. **Awards, Olympiads & Certificates**: Filterable showcase of competitions (SASMO, VANDA Science, ABRSM Violin, BISMUN) with an interactive Certificate Modal preview.
4. **Co-Curricular Activities (CCA), Sports & Music**: Highlights leadership roles, String Ensemble, Varsity Badminton, and Green Campus Club.
5. **Research Projects, Creative Works & Community Service**: Highlights STEM labs, digital art, and joint sister charity book initiatives.
6. **Live Customization & Print-to-PDF**:
   - Click **`✎ Customize Text & Photos`** to edit text directly on the page or upload custom profile photos.
   - Click **`+ Add Achievement`** to add new awards or projects.
   - Click **`🖨️ Print / Save PDF Dossier`** at the footer to generate a clean academic dossier for admissions.

## Deploying to Netlify (Optional)
1. Log in to [Netlify](https://app.netlify.com/) and click **Add new site → Import an existing project**.
2. Choose **GitHub** and select **`rchookhiatti/nudee-nadia-portfolio`**.
3. Leave Build Command empty and Publish Directory as `/` (root), then click **Deploy**.
